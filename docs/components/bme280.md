# bme280

BME280 temperature, pressure and humidity sensor (the environment sensor of the Multi-Sensor Stick).

| | |
|---|---|
| Target / option | `pico_toolset_bme280` / `PICO_TOOLSET_BUILD_BME280` (ON) |
| Links | public `pico_stdlib`, `hardware_i2c` |
| Example | `components/bme280/example/bme280_example.cpp` |
| Presets | `kPimoroniPrestoMultiSensorStick` (I2C0, 0x76; derived) |
| Boards | [Pimoroni Presto](../boards/pimoroni-presto.md) |

## API

- `Bme280Config { i2c; addr (0x76/0x77) }`; `bool init(cfg)` -- starts normal-mode conversion with Pimoroni's defaults (IIR filter 2, 0.5 ms standby, pressure x16 / temperature x2 / humidity x1).
- `Bme280Reading read()` -- `temperature_c`, `pressure_pa`, `humidity_pct`, `valid`.
- `read_forced()` -- one blocking forced-mode conversion.

Bosch Sensortec's reference driver (v4 API, BSD-3-Clause) is vendored unchanged in
`components/bme280/src/bosch/` and built with `BME280_FLOAT_ENABLE`; the class is a thin wrapper.
