# xpt2046

Reader for XPT2046-compatible resistive touch controllers sharing an SPI bus
with a display driver, plus a linear calibration helper. Implements
[`TouchPanel`](driver-interfaces.md).

| | |
|---|---|
| Target / option | `pico_toolset_xpt2046` / `PICO_TOOLSET_BUILD_XPT2046` (ON) |
| Links | public `pico_stdlib`, `hardware_spi`, `driver_interfaces`; private `hardware_gpio` |
| Example | `components/xpt2046/example/xpt2046_example.cpp` |
| Presets | `kWaveshareRp2350PiZero`, `kElecrowCrowPanelPicoHmi28`, calibration `kElecrowCrowPanelPicoHmi28Calibration` |
| Boards | [Waveshare LCD (A)](../boards/waveshare-3.5-rpi-lcd-a.md), [CrowPanel](../boards/elecrow-crowpanel-pico-hmi-2.8.md) |

## Config -- `Xpt2046Config`

| Field | Default | Notes |
|---|---|---|
| `spi_instance` | nullptr | **already `spi_init()`'d elsewhere**; take it from `lcd.spi()` |
| `pin_cs` | -- | touch controller's own CS |
| `pin_irq` | -- | PENIRQ; 255 = unused. Kept for reference only |
| `touch_freq_hz` | 2 MHz | |
| `pressure_threshold` | 300 | untuned generic value: lower if light touches are missed, raise if idle noise registers |
| `resolution` | `Bits12` | or `Bits8` |
| `power_mode` | `PowerDownBetweenConversions` | also `ReferenceOffAdcOn`, `ReferenceOnAdcOff`, `AlwaysPowered` |
| `touch_reference` | `Differential` | or `SingleEnded` |

## API -- `Xpt2046Touch : TouchPanel`

- `void init(cfg)` -- configures CS/IRQ only; never touches the SPI peripheral.
- `RawSample read()` (`RawSample` = `TouchSample`) -- detects touch from Z1/Z2
  **pressure**, deliberately not from PENIRQ, which never toggled on the SunFounder
  panel even though it is correctly wired.
- `uint16_t read_channel(Xpt2046Channel)` -- raw 0-4095 (8-bit results are
  normalised by shifting left 4). Channels: `Temp0`, `Y`, `Battery`, `Z1`, `Z2`,
  `X`, `Aux`, `Temp1`.

## Calibration (`xpt2046_calibration.h`)

`struct Xpt2046Calibration { swap_axes = true; raw_h_min = 280; raw_h_max = 3908;
raw_v_min = 3748; raw_v_max = 274; }` -- the defaults are one Waveshare 3.5" LCD
(A) unit's measured corners, a starting point and not a constant.
`xpt2046_to_pixel(sample, cal, width, height, x, y)` clamps into pixel space and
returns false when not pressed; `touch_calibration_linear_map(v, in_min, in_max,
out_min, out_max)` handles reversed ranges.

| Panel | Calibration |
|---|---|
| Waveshare / ILI9486 | the defaults above |
| SunFounder / ST7796U | defaults with `raw_h_min`/`raw_h_max` swapped (not yet a preset; TOM6809 and PicoBoot apply it in code) |
| CrowPanel 2.8" | `kElecrowCrowPanelPicoHmi28Calibration`: `swap_axes` true, horizontal `raw_y` 254..3707, vertical `raw_x` 278..3769 |

## Gotchas

- Shared-bus contract: do not call `read()` while the display has an open
  `set_window()`/`write_pixels()` sequence ([guide](../guides/shared-spi-bus.md)).
- A resistive panel produces spurious samples at touch-down; debounce
  (PiCoMonitor uses 3 polls). The vendor FAQ adds that the panel itself has
  anti-jitter delay.
