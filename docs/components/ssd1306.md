# ssd1306

I2C monochrome OLED driver with an in-RAM framebuffer, line/rectangle/text
primitives and BMP blitting. Derived from David Schramm's rpi-pico-ssd1306 (MIT).

| | |
|---|---|
| Target / option | `pico_toolset_ssd1306` / `PICO_TOOLSET_BUILD_SSD1306` (ON) |
| Links | `pico_stdlib`, `hardware_i2c` (public), `hardware_gpio` (private) |
| Example | `components/ssd1306/example/ssd1306_example.cpp` |
| Presets | none yet -- no validated board wiring; contribute one when you validate a board |

## Config -- `Ssd1306Config`

| Field | Default | Notes |
|---|---|---|
| `i2c_instance` | nullptr | **must set** |
| `sda_pin`, `scl_pin` | -- | **must set** |
| `i2c_freq_hz` | 400000 | |
| `address` | 0x3C | |
| `width`, `height` | 128, 64 | also 128x32 etc. |
| `external_vcc` | false | |

## API -- `Ssd1306`

- Lifecycle: `bool init(cfg)`, `deinit()`, `show()` (flush the buffer),
  `clear()`, `power_on()`, `power_off()`, `contrast(u8)`, `invert(u8)`.
- Drawing: `draw_pixel(x, y)`, `draw_line`, `draw_square`, `draw_empty_square`,
  `draw_char`, `draw_string`, `draw_char_with_font`, `draw_string_with_font`,
  `bmp_show_image`, `bmp_show_image_with_offset`.
- Access: `width()`, `height()`, `buffer()`, `buffer_size()`.

It does **not** implement `DisplayPanel` (wrong shape) and, being a component,
cannot implement `DisplayDriver`. Use `Ssd1306Driver` from `libs/screen` to feed
`Screen`/widgets; any colour whose RGB565 is non-zero draws the pixel on. The
primitives in `Ssd1306` itself duplicate what `DisplayDriver` offers generically
and may be trimmed later.

## Usage

```cpp
pico_toolset::Ssd1306Config cfg;
cfg.i2c_instance = i2c1; cfg.sda_pin = 19; cfg.scl_pin = 18;
pico_toolset::Ssd1306 oled;
oled.init(cfg);
oled.draw_string(0, 0, 1, "Hello");
oled.show();
```
