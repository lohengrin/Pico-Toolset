# ws2812

WS2812/SK6812 addressable-LED chain over one PIO state machine.

| | |
|---|---|
| Target / option | `pico_toolset_ws2812` / `PICO_TOOLSET_BUILD_WS2812` (ON) |
| Links | public `pico_stdlib`, `hardware_pio`; private `hardware_clocks` |
| Example | `components/ws2812/example/ws2812_example.cpp` |
| Presets | `kPimoroniPresto` (7 LEDs, GPIO33, PIO0 SM3, GRB, `gpio_base` 16) |
| Boards | [Pimoroni Presto](../boards/pimoroni-presto.md) |

## Config -- `Ws2812Config`

| Field | Default | Notes |
|---|---|---|
| `pin`, `count`, `pio`, `sm`, `order` | -- | `count` <= 64; `order` is `GRB` or `RGB` |
| `gpio_base` | -1 | RP2350B only: 0 or 16, applied before the program loads; pins >= 32 need 16 ([guide](../guides/pio-gpio-window.md)). Moves every SM already on that PIO |
| `serial_hz` | 800 kHz | |

## API -- `Ws2812`

`init(cfg)` (false if the program does not fit), `set_rgb(i, r, g, b)`,
`set_hsv(i, h 0-360, s 0-1, v 0-1)`, `clear()`, `show()` (blocking), `count()`.
The chain latches after 80 us idle.

Lineage: PIO program from pico-examples / Pimoroni plasma (BSD-3-Clause), unchanged.
