# ltr559

LTR-559 ambient light and proximity sensor (the light sensor of the Multi-Sensor Stick).

| | |
|---|---|
| Target / option | `pico_toolset_ltr559` / `PICO_TOOLSET_BUILD_LTR559` (ON) |
| Links | public `pico_stdlib`, `hardware_i2c` |
| Example | `components/ltr559/example/ltr559_example.cpp` |
| Presets | `kPimoroniPrestoMultiSensorStick` (I2C0, 0x23; derived) |
| Boards | [Pimoroni Presto](../boards/pimoroni-presto.md) |

## API

- `Ltr559Config { i2c; addr = 0x23 }`; `bool init(cfg)` checks the part id (0x09) and applies Pimoroni's defaults: ALS gain 4x, 50 ms integration and repeat, proximity LED 50 mA / 100% duty / 30 Hz / 1 pulse, proximity every 100 ms.
- `bool poll(Ltr559Reading&)` -- updates `proximity` (11 bit, larger = closer), `als_ch0/1` and `lux` when new data is ready; returns true if anything changed. Lux uses the datasheet's ratio-dependent coefficients.
- `part_id()`, `manufacturer_id()`.

No tuning API yet (gain, rates, thresholds are fixed to the defaults above).

Lineage: Pimoroni's ltr559 driver (MIT).
