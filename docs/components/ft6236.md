# ft6236

FT6236 I2C capacitive touch controller, two touch points. Implements
[`TouchPanel`](driver-interfaces.md).

| | |
|---|---|
| Target / option | `pico_toolset_ft6236` / `PICO_TOOLSET_BUILD_FT6236` (ON) |
| Links | public `pico_stdlib`, `hardware_i2c`, `driver_interfaces`; private `hardware_gpio` |
| Example | `components/ft6236/example/ft6236_example.cpp` |
| Presets | `kPimoroniPrestoHalfRes`, `kPimoroniPrestoFullRes` |
| Boards | [Pimoroni Presto](../boards/pimoroni-presto.md) |

## Config -- `Ft6236Config`

| Field | Default | Notes |
|---|---|---|
| `i2c`, `pin_sda`, `pin_scl` | -- | the driver **owns** the bus (`i2c_init` + pull-ups), unlike the SPI `TouchPanel` implementers |
| `pin_int` | -- | active-low data-ready; `0xFF` = read on every poll |
| `addr` | -- | 0x48 on Presto (0x38 on most boards) |
| `width`, `height` | -- | output coordinate space; the controller reports 0..479 |
| `rotate_180` | -- | follow a rotated display |
| `i2c_freq_hz` | 400 kHz | |

## API -- `Ft6236 : TouchPanel`

- `init(cfg)`.
- `read()` -- touch 1 in panel pixels (`raw_x`/`raw_y` are already scaled; no
  calibration step). Reads the bus when INT is low or a touch is held.
- `touch2()` -- second touch from the latest `read()`.
- `bus_ok()` -- false while backing off.

## Notes

- A NACKing controller is tolerated: after an error the driver skips the next 20
  polls, and after repeated errors clocks SCL 9 times to release a stuck SDA.
- Two fingers in the same row/column are not resolved by the controller.

Lineage: Pimoroni's `touch.py` for Presto (MIT).
